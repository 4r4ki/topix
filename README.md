# 💬 topix

友達に話しかけるのが苦手な小学6年生の男の子のための、「話しかけ方」と「鉄板ネタ」をまとめたアプリです。

現在のバージョン:**v2.0.1**([変更履歴](CHANGELOG.md))

## 内容

### 🗣️ 話しかけ方
- 話しかけレベル表(Lv.1 にこっとする 〜 Lv.7 さそう・まざる)
- 話しかける前のじゅんび、話しかけ方5つのステップ
- 場面別のそのまま使えるセリフ(朝・休み時間・給食・班活動・体育・そうじ・帰り)
- 会話の例、聞き上手になるコツ、男子どうしで仲良くなるコツ
- さそい方・ことわり方、こまったときの対処法、やらないほうがいいこと
- 練習のコツ、おうちの方へ

### 🏆 鉄板ネタ
- いつでも使える鉄板ネタ ベスト13
- 最初のひとことテンプレート、話をつづける魔法の質問
- ネタ帳:124個の話題をジャンル別に表示。タップすると「話しかけ例」と「つづける質問」が出ます
- 「知ってた?」雑学ネタ38個

画面の一番下の「全部を印刷する」で、紙にも印刷できます。

## 使い方

インストール不要の静的Webアプリです。

- **パソコンで試す**:`index.html` をブラウザで開くだけ。
- **スマホ・タブレットで使う(おすすめ)**:GitHub Pages で公開します。
  1. GitHub のリポジトリページ → **Settings** → **Pages**
  2. Branch を `main` / `/ (root)` にして Save
  3. 数分後に表示される URL(`https://<ユーザー名>.github.io/topix/`)をスマホで開く
  4. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように使えます

## 話題を追加・編集する

`topics.js` の `TOPICS` 配列に1行足すだけです。

```js
{ cat: "food", q: "話題", open: "話しかけ例", follow: ["つづける質問1", "つづける質問2"] },
// months をつけると、その月に「今月」マークがつきます
{ cat: "season", months: [12], q: "クリスマスにほしいものは?", open: "...", follow: ["..."] },
```

`cat` は `topics.js` 上部の `CATEGORIES` のどれかを指定します。雑学は `TRIVIA` 配列に文章を足してください。
話しかけ方の本文は `index.html` に直接書いてあります。

## バージョン管理

変更するときは次の手順をそろえます。

1. `version.js` の `APP_VERSION` を上げる(画面の一番下に表示されます)
   - `index.html` の `?v=2.0.1` の番号(4か所)も同じ番号にする。これを忘れると、古いファイルがブラウザに残って動かなくなることがあります
2. `CHANGELOG.md` に変更内容を書く
3. `main` に反映する
4. (おすすめ)GitHub の **Releases → Draft a new release** で、タグ(例:`v2.0.0`)をつけてリリースを作る

番号の上げ方のルールは [CHANGELOG.md](CHANGELOG.md) の冒頭にあります。
