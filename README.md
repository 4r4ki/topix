# 💬 topix

友達に話しかけるのが苦手な小学6年生の男の子のための「毎日の話題」アプリです。

## できること

- **きょうの話題**:毎日、話題が2つと季節の話題が1つ自動で変わります。
  - 💬 話しかけ例(最初のひとこと)
  - 🔁 会話をつづける質問
  - ◀ ▶ で前の日・次の日の話題も見られます(前の晩に予習できます)
- **知ってた?**:毎日ひとつ、話のきっかけになるミニ雑学
- **🎲 ほかの話題も見てみる**:ランダムに別の話題を表示
- **話しかけ方**:話しかけ方5ステップ、あいづち、タイミング、こまったときの対処法、おうちの方へのメモ
- **鉄板ネタ**:いつでも使える話題13選とテンプレート
- **きろく**:「✅ 使ってみた」の回数とバッジ、お気に入りの話題
  (きろくは端末のブラウザ内だけに保存され、外部には送信されません)

印刷用のまとめは [GUIDE.md](GUIDE.md) にあります。

## 使い方

インストール不要の静的Webアプリです。

- **パソコンで試す**:`index.html` をブラウザで開くだけ。
- **スマホ・タブレットで使う(おすすめ)**:GitHub Pages で公開します。
  1. GitHub のリポジトリページ → **Settings** → **Pages**
  2. 「Build and deployment」の Source を **Deploy from a branch**、Branch を `main` / `/ (root)` にして Save
  3. 数分後に表示される URL(`https://<ユーザー名>.github.io/topix/`)をスマホで開く
  4. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように使えます

## 話題を追加・編集する

`topics.js` の `TOPICS` 配列に1行足すだけです。

```js
{ cat: "food", q: "話題", open: "話しかけ例", follow: ["つづける質問1", "つづける質問2"] },
// months をつけると、その月だけ「季節の話題」として出ます
{ cat: "season", months: [12], q: "クリスマスにほしいものは?", open: "...", follow: ["..."] },
```

`cat` は `topics.js` 上部の `CATEGORIES` のどれかを指定します。雑学は `TRIVIA` 配列に文章を足してください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面(話しかけ方・鉄板ネタの本文もここ) |
| `app.js` | 日付ごとの話題の選び方、きろくの保存 |
| `topics.js` | 話題・雑学のデータ |
| `style.css` | 見た目 |
| `GUIDE.md` | 話しかけ方ガイド & 鉄板ネタ集(印刷用) |
